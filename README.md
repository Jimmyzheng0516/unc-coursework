# unc-coursework

My own problem sets and projects from the **B.S. in Economics and Statistics, UNC Chapel Hill** (2021–2025), plus code from two competitions. Only files I wrote are included; lecture notebooks, instructor code, textbook labs and solution files are not.

| Folder | Course / event | Content |
|---|---|---|
| `2022-fall/STOR455-statistical-methods/` | Statistical Methods I | Homework in R: regression, ANOVA, diagnostics |
| `2022-fall/ECON470-stata/` | Econometrics | Stata exercises |
| `2023-spring/STOR556-time-series/` | Time Series Analysis | Homework in R: ARIMA modelling and forecasting |
| `2023-spring/STOR572-regression/` | Applied Regression | Homework in R |
| `2023-spring/STOR415-optimization/` | Optimization | AMPL models: linear and integer programs, portfolio optimization, cash-flow matching |
| `2023-spring/ECON573-machine-learning-econ/` | Machine Learning for Economics | Problem sets in R (ISLR-based) and the group project on bank deposits |
| `2023-fall/ECON770-econometrics/` | Econometrics I (graduate) | Simulation homework in R |
| `2024-spring/STOR512-machine-learning/` | Machine Learning (Python) | Homework: support-vector machines, matrix factorization, gradient descent; final project on NASDAQ returns and financial-conditions indices |
| `2024-spring/ECON525-advanced-econometrics/` | Advanced Econometrics | Problem sets in Python and R |
| `2024-spring/ECON493-forecasting/` | Economic Forecasting | Python exercises and in-class R code |
| `competitions/fed-challenge/` | College Fed Challenge (UNC team, 2023–2025) | FRED data plots in R and two of our presentation decks |
| `competitions/uchicago-econometrics-game-2023/` | UChicago Econometrics Game | Preliminary-round data cleaning (NYC taxi data) |

My honors thesis and research-assistant work are in [`correlation-modeling-research`](https://github.com/Jimmyzheng0516/correlation-modeling-research); the FDIC Academic Challenge project is in [`fdic-deposit-panel-study`](https://github.com/Jimmyzheng0516/fdic-deposit-panel-study).

Files are committed on their last-modified date, so the history reflects when the work was done.
